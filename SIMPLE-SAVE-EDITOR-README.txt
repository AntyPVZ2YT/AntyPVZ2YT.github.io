ANTY’S SAVE EDITOR — CURRENCY, POWER-UPS & PLANT EDITING

This package contains the save editor only. Mini-games, arcade progression, game audio, and mini-game assets are not included.

Features:
- Import a pp.dat save file and export the edited save as pp.dat
- Set currencies/resources and power-ups, including 1K, 100K, 1M, 100M, 1B, and Maximum presets
- Edit recognized plant records: Numeric ID, plant level, seed packets, and mastery
- Plant search and filters for level, seeds, mastery, and known Numeric IDs
- Plant presets: All plants unlocked, Max level, Max level + max mastery, and All level 1 plants
- Optional “Set seeds = Numeric ID” action based on the Numeric ID shown for each recognized plant record

Open index.html in a compatible browser. Save editing runs locally in the browser. Keep a backup of your original pp.dat before editing. Plant fields are changed only when the save’s plant records are recognized by the editor; compatibility with every game version is not guaranteed.
